**Smart Trash Classification System**
**Overview**

Smart Trash Classification System adalah sistem berbasis Artificial Intelligence yang memanfaatkan Computer Vision untuk mengklasifikasikan jenis sampah secara otomatis berdasarkan gambar. Sistem ini dirancang untuk meningkatkan efisiensi proses pemilahan sampah serta mendukung pengelolaan limbah yang lebih tepat dan berkelanjutan. Pengguna cukup mengunggah gambar sampah, kemudian model deep learning akan memproses dan memberikan hasil klasifikasi melalui antarmuka web secara otomatis.

**Objectives**
1. Mengotomatisasi proses klasifikasi sampah menggunakan AI.
2. Meningkatkan akurasi pemilahan sampah.
3. Mendukung pengelolaan limbah yang lebih efektif.
4. Menyediakan sistem berbasis web yang mudah digunakan.

**System Workflow**
1. Pengguna mengunggah gambar sampah melalui web interface.
2. Sistem melakukan preprocessing pada gambar.
3. Model deep learning melakukan proses inferensi.
4. Hasil prediksi kategori sampah ditampilkan pada halaman web.
